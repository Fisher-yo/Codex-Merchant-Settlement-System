# 每周商家结算 SOP

## 1. 后台导出

每周五从后台导出商家总对账单，放入：

```text
01_后台总对账单
```

文件建议命名：

```text
YYYY-Wxx_MM.DD-MM.DD_后台总对账单.xlsx
```

## 2. 补充漏单和线下订单

如果发现后台总对账单不完整，不要直接修改后台原始总表，统一填写：

```text
04_异常漏单处理\手工补充订单_模板.csv
```

补充类型填写：

- `漏单补入`：商家已回传快递单号，但未及时上传后台，导致后台总对账单漏单。
- `线下会议订单`：会议现场或线下成交订单，未录入后台但本周需要结算。

关键字段：

- `供应商代号`：必须填写，否则无法合并到商家对账单。
- `预计结账金额`：必须填写，这是财务汇总金额来源。
- `补充原因`：说明为什么补入，例如“快递单号未及时上传后台”或“线下会议订单未录入后台”。
- `是否计入本周结算`：确认要计入本周时填 `是`；还没确认时填 `否`。

只有 `是否计入本周结算=是` 的行，才会被自动合并进商家对账单和财务汇总。

## 3. 拆分商家对账单

按供应商代号自动拆分单商家对账单，放入：

```text
02_商家拆分对账单
```

文件建议命名：

```text
YYYY-Wxx_MM.DD-MM.DD_供应商代号_对账单.csv
```

如果使用了手工补充订单，拆分脚本会在商家对账单里增加：

- `补充类型`
- `补充说明`

后台原始订单显示为 `后台订单`，手工补充订单显示为对应补充类型。

## 4. 发商家群对账

将单商家对账单发到对应商家群，并在 `03_商家确认记录` 的跟进台账中登记发送状态。

重点提醒商家核对：

- 订单是否完整
- 金额是否正确
- 快递单号是否已回传
- 回传快递单号是否已上传系统后台
- 手工补充订单是否认可

## 5. 处理漏单异常

如商家反馈漏单，优先核查是否属于“商家已回传快递单号，但未及时上传系统后台”。

处理方式：

1. 后台能补传的，先让商家补传后台。
2. 本周必须结算但后台暂时没有的，登记到手工补充订单台账。
3. 还没确认的，不计入本周，先登记为 `是否计入本周结算=否`。

## 6. 汇总给财务

商家确认完成后，整理财务结算汇总表，放入：

```text
05_财务汇总
```

如有手工补充订单，给财务时需说明补充原因，并附上 `04_异常漏单处理` 中的补充台账。

## 7. 钉钉审批

按 `06_钉钉审批` 中的模板填写审批内容，并上传附件。

附件建议包含：

- 财务结算汇总表
- 各商家对账单
- 商家确认记录
- 手工补充订单台账
- 异常漏单处理台账

## 8. 财务付款

财务核账完成并转款后，将付款凭证或付款记录放入：

```text
07_付款凭证
```

## 9. 收集发票

付款后跟进商家开票，将发票文件放入：

```text
08_发票资料
```

并维护发票收集台账。
