# 创建新周结算目录使用说明

在 PowerShell 中进入本目录：

```powershell
cd ".\workspace\04_商家周结算\99_结算模板与规则"
```

执行：

```powershell
.\创建新周结算目录.ps1 -WeekCode "2026-W22" -Period "05.25-05.31"
```

执行后会创建：

```text
workspace\04_商家周结算\2026\2026-W22_05.25-05.31
```

新目录会自动包含后台总对账单、商家拆分对账单、商家确认记录、异常漏单处理、财务汇总、审批、付款凭证、发票资料和模板话术等子目录。
