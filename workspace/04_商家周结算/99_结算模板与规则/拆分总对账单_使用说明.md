# 拆分总对账单使用说明

用途：把后台导出的总对账单按 `供应商代号` 自动拆分成单个商家的对账单，并同步生成财务汇总表和商家跟进台账。

## 使用步骤

1. 先用 `创建新周结算目录.ps1` 创建本周结算目录。
2. 把后台导出的总对账单放进本周目录的 `01_后台总对账单`。
3. 在 PowerShell 中执行拆分命令。

示例：

```powershell
cd "D:\codex\fuyu-codex\codex-list"

powershell -NoProfile -ExecutionPolicy Bypass -File ".\workspace\04_商家周结算\99_结算模板与规则\拆分总对账单.ps1" `
  -InputFile ".\workspace\04_商家周结算\2026\2026-W22_05.25-05.31\01_后台总对账单\对账单_20260530_111353.xlsx" `
  -OutputDir ".\workspace\04_商家周结算\2026\2026-W22_05.25-05.31" `
  -Period "2026-W22_05.25-05.31"
```

如果本周有漏单或线下订单需要补入，先填写：

```text
04_异常漏单处理\手工补充订单_模板.csv
```

然后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\workspace\04_商家周结算\99_结算模板与规则\拆分总对账单.ps1" `
  -InputFile ".\workspace\04_商家周结算\2026\2026-W22_05.25-05.31\01_后台总对账单\对账单_20260530_111353.xlsx" `
  -OutputDir ".\workspace\04_商家周结算\2026\2026-W22_05.25-05.31" `
  -Period "2026-W22_05.25-05.31" `
  -SupplierMapFile ".\workspace\04_商家周结算\99_结算模板与规则\供应商代码映射表_模板.csv" `
  -SupplementFile ".\workspace\04_商家周结算\2026\2026-W22_05.25-05.31\04_异常漏单处理\手工补充订单_模板.csv"
```

重新运行脚本前，请先关闭已经打开的商家对账单、财务汇总表和跟进台账文件，否则 Excel 可能占用文件导致覆盖失败。
