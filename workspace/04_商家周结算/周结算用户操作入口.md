# 周结算用户操作入口

用途：把本项目中已经完成的周结算脚本、模板和台账，整理成用户视角的一套简洁操作。使用者不需要逐个目录找文件，只按本页流程处理即可。

## 一句话流程

新建本周结算包 -> 放入后台总对账单 -> 一键拆分 -> 发商家确认 -> 汇总给财务 -> 跟进付款和发票。

## 用户主界面建议

当前已经提供第一版操作台：

```text
周结算操作台.ps1
```

也可以从项目根目录运行：

```text
启动周结算操作台.cmd
```

首页保留 4 个主要动作：

```text
[新建本周结算]  [导入后台总对账单]  [生成结算结果]  [查看本周结果]
```

辅助入口放在右侧或底部：

```text
规则与模板 | 商家代码映射 | 手工补充订单 | 商家确认台账 | 财务汇总表 | 发票台账
```

## 1. 新建本周结算

用户要做的事：

- 输入周次，例如 `2026-W22`。
- 输入周期，例如 `05.25-05.31`。
- 点击“新建本周结算”。

系统实际执行：

```powershell
.\99_结算模板与规则\创建新周结算目录.ps1 -WeekCode "2026-W22" -Period "05.25-05.31"
```

生成结果：

```text
2026\2026-W22_05.25-05.31
```

里面会自动带出后台总对账单、商家拆分对账单、商家确认记录、异常漏单处理、财务汇总、钉钉审批、付款凭证、发票资料等工作目录。

## 2. 导入后台总对账单

用户要做的事：

- 从后台导出本期总对账单。
- 拖入软件窗口，或放入本周目录的：

```text
01_后台总对账单
```

建议文件命名：

```text
2026-W22_05.25-05.31_后台总对账单.xlsx
```

软件需要识别的核心字段：

- `供应商代号`
- `预计结账金额`

## 3. 手工补充订单

适用情况：

- 后台漏单。
- 线下会议订单要计入本周结算。
- 商家已回传快递单号，但后台还没有及时同步。

用户要做的事：

- 打开本周目录：

```text
04_异常漏单处理\手工补充订单_模板.csv
```

- 填写补充订单。
- 确认要计入本周时，把 `是否计入本周结算` 填成 `是`。

注意：

- `供应商代号` 必须填。
- `预计结账金额` 必须填。
- 还没确认的订单先填 `否`，不要计入本周。

## 4. 生成结算结果

用户要做的事：

- 点击“生成结算结果”。
- 如果没有手工补充订单，直接生成。
- 如果有手工补充订单，系统自动把计入本周的补充订单合并进去。

系统实际执行：

```powershell
.\99_结算模板与规则\拆分总对账单.ps1 `
  -InputFile "本周目录\01_后台总对账单\后台总对账单.xlsx" `
  -OutputDir "本周目录" `
  -Period "2026-W22_05.25-05.31" `
  -SupplierMapFile ".\99_结算模板与规则\供应商代码映射表_模板.csv" `
  -SupplementFile "本周目录\04_异常漏单处理\手工补充订单_模板.csv"
```

生成结果：

- `02_商家拆分对账单`：每个商家一份对账单。
- `03_商家确认记录`：商家对账跟进台账。
- `05_财务汇总`：财务结算汇总表。
- `99_异常待处理`：空供应商、统计行、无法拆分内容。

## 5. 发商家确认

用户要做的事：

- 打开 `02_商家拆分对账单`。
- 把对应商家的对账单发到商家群。
- 在 `03_商家确认记录` 里记录是否已发送、是否已确认、是否有异常。

给商家的核对重点：

- 订单是否完整。
- 金额是否正确。
- 快递单号是否回传。
- 漏单或线下订单是否认可。

## 6. 汇总给财务

用户要做的事：

- 打开：

```text
05_财务汇总
```

- 检查财务结算汇总表。
- 如果有手工补充订单，把补充原因一起说明。

财务需要看的内容：

- 商家代码。
- 商家名称。
- 订单数。
- 预计结账金额合计。
- 对账确认状态。
- 发票状态。
- 付款状态。

## 7. 钉钉审批、付款和发票

钉钉审批：

- 使用 `06_钉钉审批` 中的模板。
- 上传财务汇总表、商家对账单、商家确认记录、补充订单台账。

付款凭证：

- 财务付款后放入：

```text
07_付款凭证
```

发票资料：

- 商家开票后放入：

```text
08_发票资料
```

- 同步维护发票收集台账。

## 软件化后的推荐页面

### 首页：本周结算

- 当前结算周期。
- 后台总对账单拖入区。
- 生成结算结果按钮。
- 生成结果摘要：商家数、订单数、预计结账金额、异常行数。

### 结果页：自动生成内容

- 商家拆分对账单。
- 财务汇总表。
- 商家确认台账。
- 异常待处理。

### 配置页：不常用设置

- 供应商代码映射。
- 拆分字段，默认 `供应商代号`。
- 金额字段，默认 `预计结账金额`。
- 导出命名规则。

### 异常页：只处理问题

- 空供应商行。
- 后台统计行。
- 手工补充但未计入订单。
- 商家反馈漏单。
