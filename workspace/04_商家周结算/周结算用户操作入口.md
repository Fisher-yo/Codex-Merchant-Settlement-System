# 周结算用户操作入口

## 日常流程

1. 打开根目录的 `启动周结算操作台.cmd`。
2. 确认年份、后台导出日期和对账日期。
3. 点击“新建本周结算”。
4. 拖入后台导出的总对账单 `.xlsx`。
5. 如有漏单或线下订单，填写本周目录里的 `04_异常漏单处理\手工补充订单_模板.csv`。
6. 点击“生成结算结果”。
7. 打开结果目录，把商家对账单发给商家确认，并把财务汇总表交给财务。

## 输入要求

后台总对账单需要包含：

- `供应商代号`
- `预计结账金额` 或 `预计结算金额`

如需显示商家名称，维护：

```text
99_结算模板与规则\供应商代码映射表_模板.csv
```

## 生成结果

点击“生成结算结果”后，会在本周目录生成：

- `02_商家拆分对账单`：每个商家一份对账单
- `03_商家确认记录`：商家对账跟进台账
- `05_财务汇总`：财务结算汇总表
- `99_异常待处理`：空供应商、统计行等无法拆分内容

## 手工补充订单

补充订单文件路径：

```text
04_异常漏单处理\手工补充订单_模板.csv
```

必填重点：

- `供应商代号`
- `预计结账金额`
- `是否计入本周结算`

只有 `是否计入本周结算` 不是“否 / 不计入 / no / 0”的行，才会合并进本周结算。
